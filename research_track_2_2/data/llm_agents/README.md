# Genuine LLM trajectory files

The guarded `src.real_cli run-game` command writes native starter-run JSON under `source_runs/` and appends parsed trajectories to `trajectories.jsonl`. `prepared_monitor_views.jsonl` is generated offline. Earlier pilot run files and parsed records were cleared on 2026-10-25 at the user's request. This folder is now an output location for the fresh pilot and main run; provider-reported usage from the cleared runs was unavailable.
